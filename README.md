# AI 订阅导航

适用于 GitHub Pages 的静态网站，主题为 GPT / Claude 账号代充与订阅导航。

当前已完成：产品介绍、两个官方入口、关键词搜索、产品筛选、名称排序和收录说明。尚未收录第三方商家报价，不声称最低价、稳定性或全网覆盖。

网站文件：index.html、styles.css、script.js、.nojekyll。

本地预览：在本目录运行 python -m http.server 8765，然后打开 http://localhost:8765。

上线方式：上传以上网站文件到仓库 main 分支的根目录，在 Settings → Pages 选择 Deploy from a branch、main、/(root)。

报价维护要求：记录来源链接、采集日期、套餐、币种、周期、交付方式及退款条件；缺失项标注待核验。同币种、同套餐、同周期才能直接比价。页面尚无价格排序，待真实报价收录后按上述口径添加。
